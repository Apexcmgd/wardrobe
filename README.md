# 个人数字衣橱（Digital Wardrobe）

一款专为手机移动端优化（同时完美兼容桌面端）的现代个人衣物管理与数字衣橱 Web 应用。通过拍照录入衣服、多级分类管理、智能仓库展示、折叠浏览以及本地离线持久化存储，帮助你轻松整理和管理日常衣物。

---

## ✨ 核心特性

- 📸 **快速拍照录入**：支持直接调用手机后置高清相机拍照或本地相册上传，自带 Canvas 高清压缩，避免占用手机过多存储空间。
- ⚡ **自动分类弹窗**：拍照/选图完成后自动打开分类选择界面，无需繁琐的二次点击。
- 🏷️ **灵活多级分类**：支持一级分类与二级分类，可直接在录入过程中一键新建分类并自动选中；支持无二级分类（如羽绒服）直接保存。
- 📂 **独立展开与折叠**：每个一级分类、二级分类支持独立折叠，互不干扰；提供“全部展开”与“全部折叠”快捷操作，自动记忆折叠偏好。
- 🔍 **多维度搜索与筛选**：支持按衣物名称、一级分类、二级分类、备注关键词实时搜索与排序。
- 💾 **本地持久化存储**：基于浏览器 IndexedDB，照片与分类数据完全保存在手机/电脑本机，刷新、关闭不丢失，极大保护个人隐私。
- 📦 **数据备份与恢复**：一键导出全量 JSON 备份包（含全部分类和照片数据），在新设备或清空环境下可完整恢复。
- 📱 **PWA 移动端优化**：支持直接“添加到手机主屏幕”，全屏无地址栏运行，媲美原生 App 体验。

## 📱 如何在手机上使用？

### 方式一：局域网同一 Wi-Fi 直接访问（最快）

1. **连接同一 Wi-Fi**：确保手机和电脑连接在同一个无线路由器（Wi-Fi）下。
2. **手机打开网址**：
   - 在手机浏览器中输入：`http://192.168.1.13:5173/`
   - 或者在电脑页面点击右上角的 **【手机访问】** 按钮，直接用手机微信或相机扫一扫二维码。
3. **添加到手机主屏幕（强烈推荐）**：
   - **苹果 iPhone (Safari)**：点击浏览器底部的【分享】按钮 ➔ 向下滑动选择【添加到主屏幕】。
   - **安卓手机 (Chrome/自带浏览器)**：点击右上角菜单 ➔ 选择【添加到主屏幕】或【安装应用】。
   - 之后在手机桌面上会生成独立的“数字衣橱”图标，点击即全屏打开，随时随地单手拍照录入衣服！

### 方式二：免费部署到云端（出门在外随时可用）

如果希望出门在外不用电脑开机也能随时使用，只需将本项目打包后免费托管到 **Vercel**、**Cloudflare Pages** 或 **GitHub Pages**：
```bash
npm run build
```
将生成的 `dist` 目录上传托管，即可获得一个永久的公网 `https://` 网址，数据仍然保存在你的手机本地，快速且私密！

## 🛠️ 本地开发与构建

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地服务（支持局域网手机访问）
```bash
npm run dev
```
启动后终端会显示手机可访问的局域网地址（如 `http://192.168.1.13:5173/`）。

### 3. 运行自动化测试
```bash
npm test
```
包含 8 项针对分类层级、衣物录入、删除迁移、数据导入导出的单元测试。

### 4. 构建生产版本
```bash
npm run build
```
输出文件位于 `dist` 目录。
